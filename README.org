* Cascading Failures on Spatial Networks (Motter–Lai Model)

Simulates Motter–Lai cascading failures on ζ-model spatial networks
(torus topology).  Written in C++20 with Boost.Graph and OpenMP.

** Dependencies

- Boost ≥1.73 (Boost.Graph — headers-only)
- OpenMP (included with GCC, or libomp for Apple Clang)
- CMake ≥3.16

** macOS

#+begin_src sh
brew install boost libomp cmake
cmake -B build -DCMAKE_BUILD_TYPE=Release -DOpenMP_ROOT="$(brew --prefix libomp)"
#+end_src

** Linux (x86_64)

OpenMP is provided by GCC — no extra install needed.

Option A — install Boost from your package manager (simpler):

#+begin_src sh
sudo apt install build-essential cmake libboost-dev-all
cmake -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build
#+end_src

Option B — download Boost headers with curl (works on any distro):

#+begin_src sh
sudo apt install build-essential cmake
curl -L https://archives.boost.io/release/1.87.0/source/boost_1_87_0.tar.bz2 | tar -xj
cmake -B build -DCMAKE_BUILD_TYPE=Release -DBOOST_ROOT=$PWD/boost_1_87_0
cmake --build build
#+end_src

** Build

#+begin_src sh
cmake -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build
#+end_src

** Run

#+begin_src sh
./build/cascade               # default: L=50, ζ=15
./build/cascade 30 10         # L=30, ζ=10
#+end_src

The simulation parallelises over θ values (OpenMP).  Each (θ, p)
combination runs a full Brandes betweenness centrality per cascade step.
Expect several minutes for the default L=50 config.

Post-process results:

#+begin_src sh
python plot_results.py
#+end_src

** Output

CSVs are written to =results/CSV/L = …/zeta = …, k = …, alpha = …/=:
- Giant component size S(p, θ) and cascades time t(p, θ)
- Final degree distribution per (θ, p) pair

Plots (PNG) are generated by =plot_results.py= into the corresponding
=results/plots/= subdirectory.

** Source layout

- =src/main.cpp= – entry point, constants, parallel dispatch, CSV output
- =src/simulate.h/cpp= – seed failure, θ-weights, Motter–Lai cascade
- =src/graph_generators.h/cpp= – graph type, ζ_taurus, BA, ER generators
- =src/util.h/cpp= – degrees, degree distribution, giant component, CSV writer
- =plot_results.py= – standalone matplotlib visualisation

** Differences from the original Julia code

- Boost.Graph replaces the custom graph, Dijkstra, Brandes, and
  connected-components implementations
- OpenMP replaces Julia's =@distributed SharedArrays=
- =clear_vertex= fixes a neighbour-iteration bug in the original cascade
  loop (Julia skipped ~half the neighbours)

** Caveats

- =vecS= edge storage is used for cache locality; edge descriptors are
  not stable across mutations, but the cascade rebuilds the graph each
  iteration so this is safe
- Apple Clang does not support capturing structured bindings in OpenMP
  regions — explicit variables are used instead
- =brandes_betweenness_centrality= may throw on degenerate graphs; the
  cascade catches exceptions as a safety net
